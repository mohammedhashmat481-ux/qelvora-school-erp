# Qelvora School ERP - Assistant Guidelines

## Strict Image & Screenshot Policy
- **NO SCREENSHOTS**: Never capture, store, or generate screenshots (`.png`, `.jpg`, etc.) anywhere in the workspace, project folders, or artifacts.
- **Verification Method**: Always verify work using code analysis, automated terminal builds (`npm run build`), unit checks, and text/markdown summaries.
- **Quota & Cleanliness**: Preserve the user's AI quota credits and keep project directories 100% clean of clutter and temporary media assets.
